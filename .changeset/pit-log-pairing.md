Pit's Logs page shows how to set up a pit log downloader on Windows, macOS or Linux and gives mentors and admins a code to pair it with, and the downloader asks for that code and the team number when it starts, before it copies anything. Once paired, its status page takes the team's colors, names and logo from Gearbox, and it uploads match logs to Pit, whose Logs page lists them to download (mentors and admins can delete them). Google Drive isn't used any more.
