Edge's buttons and text boxes are the same ones the other apps use, so they are the same size and show the same focus ring. Buttons that were plain text ("Check again", "Revoke", "Make default") now have an outline. Making a new box key, deleting a blocklist and removing a printer ask in the page, not in a browser pop-up, and deleting a door sound now asks first.
