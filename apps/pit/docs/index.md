Pit is for competitions. Before each match the crew runs its checklists; problems found become issues until someone fixes them. Batteries are tracked from charger to robot. A screen in the pit shows it all, with the next match.

## Pages

| Page | What it's for |
| --- | --- |
| Overview | Checklist progress, open issues, the batteries Next Up and In Robot, and the next match |
| Checklists | Run a checklist: tick items, report issues |
| Edit Checklists | Make and change checklists and their items |
| Batteries | Every battery, its voltage and where it is |
| Archives | Every "Archive and reset": the state of every list at that moment |
| Logs | The robot's match logs, copied off by the pit log downloader |
| Monitor | A full-screen display for the pit |
| Admin | The event, and the Monitor's feed |

Anyone signed in uses Pit, kiosks too. Admins change its settings.
