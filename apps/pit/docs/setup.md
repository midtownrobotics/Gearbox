## Checklist

- [ ] On [Admin](team:pit/admin), enter the event's **TBA Event Key** (such as `2026gacmp`), and its **Nexus Event Key** if the event uses Nexus
- [ ] On [Edit Checklists](team:pit/editor), write your checklists: "Pre-match", "Battery swap", "Post-match"
- [ ] On [Batteries](team:pit/batteries), add each battery with a name, and print labels for them
- [ ] Put the [Monitor](team:pit/monitor) up on a screen in the pit
- [ ] If you want match logs, [pair a log downloader](logs)

## The event

The event key is how Pit knows your next match. With The Blue Alliance's key alone it gets the schedule from The Blue Alliance; at an event that uses Nexus, add Nexus's key too for live queuing. Nothing else to set up: Gearbox has the keys for both services.

Change the key for each event. Between events, the Overview shows your last archive instead of a next match.

## The Monitor's feed

**Custom Monitor Feed URL** puts a page of your choice on the Monitor, such as a stream of the field or a dashboard. Leave it empty for none.
