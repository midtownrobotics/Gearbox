## Run a checklist

Open [Checklists](team:pit/checklists) and pick a list. Tick each item as it's checked. If something's wrong, report an issue on the item, with details. Open issues stay on the Overview and the Monitor until someone marks them resolved.

## Archive and reset

After each match, choose **Archive and reset**. It saves every list, item and issue as they are, with the match ("Qual 42", filled in from the schedule), then unchecks everything for the next one. Open issues stay open.

The [Archives](team:pit/archives) page lists every archive. Open one to see what was checked and which issues were new, still open or resolved since the one before.

A list's own **Reset this list** unchecks it without saving an archive.

## Edit checklists

On **Edit Checklists**, add lists and items, and put them in order. Editing needs a connection; running a checklist keeps working when the pit's Wi-Fi drops.
