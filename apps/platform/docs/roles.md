Every member of a team has one account. Roles are set on Portal's Members page (in Portal's section, after this one) and apply in every app.

## Team roles

| Role | Who it's for | What it adds |
| --- | --- | --- |
| Student | Every approved member | Uses the apps: requests parts, checks items, scouts, signs in |
| Mentor | Mentors | Approves orders, signs off skills, edits schedules and catalogs, deletes and merges in Inventory |
| Admin | A few people who look after Gearbox | The team's admin pages, and each app's **Admin** page |

A person can be both a mentor and an admin. An admin who isn't a mentor is treated as a student in apps that count students, like Skill Tree.

## Roles inside an app

Some apps let you trust particular members with more:

- **Orders:** trusted students edit the parts catalog, like mentors. Set on Orders' Admin page.
- **Schedule:** trusted members edit schedules. Set on Schedule's Admin page.
- **Scouting:** strategy leads run Scouting like its admins, and the service crew gets the robot's service tickets. Set on Scouting's Admin page.

## New members

Someone who signs up through your team's chat waits for approval. Every admin who has linked the team's chat gets a message with their name and a link to approve them. Until then they can't open any app.
