[Lists](team:orders/lists) group requests for a project: "Swerve rebuild", "Spares for champs". A request can be on several lists.

- **New list** makes one, with a name and an optional description. Anyone can.
- **Add requests** from the list's page: **Request parts** to request new ones straight onto it, or search requests already made to add them. On a request's page, **Add to a list…** does the same.
- Each list shows how many of its parts are waiting, approved, ordered and arrived, and what it all costs. Denied and canceled requests don't count toward it.
- **Find on this list** searches a long list by size, SKU, person or status; small typos are fine.
- **Edit list** renames it or changes its description.

Only whoever made a list, or a mentor, edits, archives or deletes it. The requests on it are never touched.
