Orders replaces the team's ordering spreadsheet. Any member asks for a part with a link, a quantity, a budget category and an optional reason. Mentors approve or deny it, group approved parts into one order per vendor, and mark them ordered with what they really cost. Whoever opens the box marks it received.

A request goes: **requested → approved → ordered → received**, or denied, or canceled before it's ordered.

## Who does what

| | Students and kiosks | Trusted students | Mentors and admins |
| --- | --- | --- | --- |
| Browse the catalog, request parts, use the wishlist and lists | Yes | Yes | Yes |
| Mark deliveries received | Yes | Yes | Yes |
| Add and edit catalog parts and categories | | Yes | Yes |
| Approve, deny, order, edit budgets and vendors | | | Yes |
| The Admin page | | | Yes |

## Pages

| Page | What it's for |
| --- | --- |
| Requests | Every request, grouped by status. Filter, search, or show only yours |
| New Request | The parts catalog: search it, or paste a link to request something new |
| Wishlist | Parts the team would like one day, to promote to requests later |
| Lists | Named groups of requests: "Swerve rebuild", "Spares for champs" |
| Approvals | Mentors: approve, deny or replace what's waiting |
| Carts | Mentors: approved parts grouped by vendor, ready to order |
| Deliveries | What's on its way, and marking it received |
| Budget | Spending against each category's budget, by fiscal year |
| Vendors | Mentors: each vendor's shipping, minimums, lead times and credits |
| Admin | Mentors: currency, fiscal year, tax, naming, trusted students, Share-A-Cart |
