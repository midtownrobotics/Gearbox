title: Inventory

order: 15
---

Inventory keeps one entry per kind of part ("1/2 in. hex bearing"), counted in each place it's kept. A place is a storage location (a room, a cabinet, a drawer, a bin), or a location plus the robot and subsystem the parts are in use on. Checking parts out moves them onto a robot; checking them in brings them back.

Every change to an entry is in its History, with who made it.

## Who does what

| | Everyone | Mentors | Admins |
| --- | --- | --- | --- |
| Add and edit entries, count, move, check out and in | Yes | Yes | Yes |
| Describe locations and move everything in one | Yes | Yes | Yes |
| Delete, merge and split entries | | Yes | Yes |
| The Admin page: fields, locations, robots, subsystems, units | | | Yes |
