[Locations](team:inventory/locations) turns the table around: your locations as nested panels, each with what's kept directly in it.

- **Open all** and **Close all** open or close every panel. Search finds a location, a description or a part. Going back to Locations from an entry's page keeps the same panels open and the same search.
- **Add here** adds a new kind of part kept in that location, in a pop-up with the location already picked, so you can fill a shelf without choosing its location each time. After each entry you're back at that location's **Add here**, ready for the next.
- **Add description** says what's kept somewhere ("Misc. electronics"). Press Enter or click away to save, Escape to cancel. It then shows with the location's name everywhere.
- **Move** moves one entry's parts from here.
- **Move all** moves everything in the location somewhere else, when you reorganize a shelf. Parts join the same entry's parts already there.

The locations themselves stay where they are: an admin changes those on the Admin page.
