On [Manage Apps](team:portal/admin), each app has a switch. A new team starts with none on; sign-in and the home page are always on.

## Switching an app on

The app appears on everyone's home page and in the menu at once. Some apps start with something to work from: Skill Tree with a default set of trees, Orders with a starter parts catalog. Each app's section, later in these docs, ends with how to set it up.

Every admin who has linked the team's chat gets a message when an app is switched on or off.

## Switching an app off

- The app disappears for everyone straight away. Its addresses say it isn't switched on.
- **Its data is kept for 90 days.** Switch it back on within that time and everything is as it was.
- After 90 days its data is deleted, and that can't be undone.
- Before you switch an app off, the page offers its data as a download (a JSON file). Download it if you might want it later.

Features that need another app hide while that app is off. For example, Orders' part lookup needs Edge, and Inventory's links to the parts catalog need Orders.

## The team's log

Below the apps is the team's log: apps switched on and off, data downloads, and big settings changes in any app (which settings changed and who changed them, never the values).
